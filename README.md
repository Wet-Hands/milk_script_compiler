# The milk_script Compiler

## What is milk_script?
This is a CompSci project for me to get my head back in the game. I wanted to write a Rust-like language with syntax I am more familiar with from working in C and Go. The idea is that it's supposed to be easier to type in comparison to C++ and Rust.

## Is milk_script right for me?
Probably not. Rust already exists, and is battle-tested. Only use this if you are opinionated.
